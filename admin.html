Categories

Groups

Manufacturer-style groupings a subcategory can collapse under (e.g. "Sega" so Genesis/32X/Saturn nest under one heading instead of listing dozens of platforms at once). Picked from a list everywhere else so a typo can never split one manufacturer into two — no photo needed for these.

Subcategories

Optional sub-grouping within a category — e.g. DC / Marvel / Image within Comics, or Sega Master System / NES / Arcade within Video Games. Shown as cover-photo tiles or a dropdown depending on that category's setting above.

Item Types

Only used by categories set to the "Tree" browsing style above — a top-level split like Consoles / Games / Accessories within Video Games. Categories on Tiles or Dropdown don't need these.

Bulk Import (CSV)

Upload a CSV with these columns: title, category, brand, condition_grade, release_year, highlight_note, condition_notes, description, cost_basis, asking_price, quantity, status (brand, condition_grade, release_year, and highlight_note are all optional). The category value must match an existing category slug (e.g. comics), and brand must match an existing brand slug — add those first above if they don't exist yet. Items import with no photo and show up in the compact list view on the catalog page until you add photos individually. Rows whose title exactly matches an item already in your inventory are skipped automatically (use the quantity column for multiple copies of the same item instead of separate rows).
