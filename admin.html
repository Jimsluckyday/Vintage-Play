Bulk Import (CSV)

Upload a CSV with these columns: title, category, brand, condition_notes, description, cost_basis, asking_price, quantity, status (brand is optional — leave blank if not using brand tiles for this category). The category value must match an existing category slug (e.g. comics), and brand must match an existing brand slug — add those first above if they don't exist yet. Items import with no photo and show up in the compact list view on the catalog page until you add photos individually. Rows whose title exactly matches an item already in your inventory are skipped automatically (use the quantity column for multiple copies of the same item instead of separate rows).
